# Identione apps

Download links for the Identione Android tenant apps. The files are built and signed by the release workflow of the Identione server repository. Each release here has a fixed tag, and the file in it is replaced on each new build. The link to a file does not change.

| App | Download |
| --- | --- |
| Identione (pilot) | https://github.com/Identione/identione-apps/releases/download/pilot-tenant-android/identione.apk |
| Identione (demo) | https://github.com/Identione/identione-apps/releases/download/demo-tenant-android/identione-demo.apk |

The release notes of each release name the app version, the version code and the source commit.
